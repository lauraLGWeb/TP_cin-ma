🎬 Cinéma de plein air — TP HTML/CSS

Projet scolaire consistant à réaliser un mini-site complet autour d’un cinéma de plein air.
Le site contient une page d’accueil présentant les films, une page de réservation et une page de contact.


structure du projet : 

/cinema-plein-air
│── index.html        → Page d'accueil (films, infos, à propos)
│── reservation.html  → Réservation des places
│── contact.html      → Formulaire + Google Maps
│── styles.css        → Style général (Flexbox, animations, responsive)
│── /images           → Images des films + illustrations


⭐ Fonctionnalités du site
Accueil

Présentation des films sous forme de cartes (image + titre + description)

Section “À propos”

Mise en page en colonnes avec Flexbox

Animation fluide à l’apparition des cartes

Réservation

Formulaire de réservation : nom, email, film, nombre de places, date…

Mise en page claire et responsive

Contact

Formulaire de contact simple

Carte Google Maps intégrée montrant l’emplacement du cinéma

Informations de contact

🎨 CSS & animations

Flexbox pour organiser les cartes et sections

Animations douces à l’apparition des éléments (transition, opacity, transform)

Design responsive pour mobile, tablette et desktop

Styles partagés entre toutes les pages via styles.css

🚀 Installation & utilisation

Télécharger le projet

via ZIP : Code → Download ZIP

ou en clonant : git clone https://github.com/ton-repo/cinema-plein-air.git
Placer le dossier sur ton ordinateur

Ouvrir le site

Double-cliquer sur index.html

Ou ouvrir les fichiers dans un navigateur (Chrome, Firefox…)

Éditer / modifier

Ouvrir le projet dans Visual Studio Code

Modifier les fichiers .html pour le contenu

Modifier styles.css pour le design

Aucune installation de package, serveur ou dépendance : le site fonctionne simplement en HTML/CSS.`

📸 Images

Place les images de tes films dans un dossier /images puis référence-les dans tes cartes.
Exemple :<img src="images/film1.jpg" alt="Nom du film">
